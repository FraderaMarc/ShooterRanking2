Política de privacidad de Shooter Ranking

Versión 1.1 · 11 de agosto de 2026

Responsable: Marc Fradera Bigas · Contacto: info@shooterranking.com.

Datos tratados

La aplicación puede tratar correo electrónico, nombre de usuario, identificador de cuenta, estado de verificación y los datos deportivos introducidos por el usuario (temporadas, equipos, nombres de jugadores, sesiones y estadísticas). La contraseña es gestionada por Firebase Authentication y no se almacena como parte del perfil de Shooter Ranking.

Finalidades y proveedores

Los datos se usan para crear y autenticar la cuenta, sincronizar datos deportivos, calcular estadísticas, generar documentos, mantener la seguridad y atender solicitudes. Shooter Ranking usa Firebase Authentication y Cloud Firestore y puede usar Google AdMob; cuando sea exigible se gestiona el consentimiento publicitario mediante Google UMP.

Conservación y eliminación

Los datos se conservan mientras la cuenta esté activa y sean necesarios para prestar el servicio. El usuario puede eliminar la cuenta desde la configuración de la app. También puede solicitar la eliminación mediante la página de eliminación de cuenta.

Derechos

Cuando corresponda, puedes ejercer acceso, rectificación, supresión, limitación, oposición y portabilidad escribiendo al contacto indicado. También puedes reclamar ante la Agencia Española de Protección de Datos.

Datos de terceros y menores

Si introduces datos de jugadores u otras personas, eres responsable de disponer de una base legítima. Limita especialmente los datos de menores a lo estrictamente necesario.

Seguridad y transferencias

Aplicamos medidas razonables de seguridad. Los proveedores internacionales pueden implicar transferencias internacionales sujetas a las garantías legalmente aplicables. No vendemos datos personales.
